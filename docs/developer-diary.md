### 1. 正式前端工程启动

顺着前一轮“建议进入正式前端工程”的记录，本轮已开始将静态原型迁移到真正的 Web 前端工程中。

### 4. 修复管理端切换登录失败

问题表现：

- 本地实验时切换到“管理老师”后无法正常进入管理端。

原因：

- 登录页切换模拟角色时，用户名仍停留在学生账号 `20220001`。
- mock 登录逻辑会优先按当前输入用户名匹配账号，导致实际登录身份仍是学生，进入管理端时被路由权限拦截。

修复内容：

- 登录页切换角色时自动填入对应演示账号：
  - 普通学生：`20220001 / 123456`
  - 班团骨干：`20220018 / 123456`
  - 管理老师：`teacher001 / 123456`
  - 学院领导：`leader001 / 123456`
- mock 登录在指定管理角色时严格匹配对应角色账号，避免学生账号误登录到管理端流程。
