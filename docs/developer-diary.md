## 2026-05-18

### 1. 正式前端工程启动

顺着前一轮“建议进入正式前端工程”的记录，本轮已开始将静态原型迁移到真正的 Web 前端工程中。

本轮决策如下：

- 采用 `Vue 3 + Vite + Vue Router + Pinia` 作为正式前端技术栈
- 保留仓库根目录下现有静态原型文件作为视觉与交互参考
- 在仓库内新增 `web/` 目录，作为正式前端工程承载位置

这样做的原因是：

- 避免在静态 HTML 上继续叠加复杂逻辑
- 保持原型可回看，同时让正式工程独立演进
- 便于后续逐步替换为真实 API，而不打乱现有资料结构
